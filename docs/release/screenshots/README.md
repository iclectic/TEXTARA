# Store screenshots & preview

Capture these on real devices or simulators before Play / App Store submission. Prefer the **Porcelain** or **Parchment** theme and a small DRM-free sample library.

## Phone (portrait)

1. **Library** — grid with several covers, search icon visible.
2. **Reader** — EPUB page with chrome visible (title, progress, typography comfortable).
3. **Annotations** — highlight colours + note sheet.
4. **Idea Threads** — thread with two evidence cards and an insight chip.
5. **Settings / a11y** — accessibility toggles (dyslexia, high contrast, reduced motion).

## Tablet (landscape)

1. **Library wide** — grid or list with filter chips.
2. **Reader wide** — generous margins; optional TOC open.

## Preview video (~20–30s)

1. Import an EPUB.
2. Open reader, change theme once.
3. Highlight a sentence, add to Idea Thread.
4. Open Threads and show local insight.
5. End on library — calm, no paywall UI.

Place exported PNGs / MP4s in this folder when ready (`phone-library.png`, `phone-reader.png`, …). Do not commit large raw screen recordings unless needed for review.
